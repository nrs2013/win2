新しい Windows を受け取った人へ

新しい Windows の準備をお願いします

上から順に 6つ、全部で 約30分。終わったら のむさん に番号を1つ送って終わりです。その後は のむさん と AI が遠くから進めます。

のむさん に LINE するのは3回だけ

  1. 始める前に：新しい PC の「owner」のパスワードを聞く
  2. 手順6の途中：画面に出た https://login.tailscale.com/… の URL をそのまま送る
  3. 最後に：画面に出た 100. で始まる番号を送る

  1. 箱から出して、初期設定を終える 約10分

    LAN ケーブル（有線）・電源・モニター・キーボード・マウスをつないで起動し、画面の案内どおりに進めます。

    Microsoft アカウントを聞かれたら、会社か のむさん のアカウントで入ります（自分個人のアカウントは使わない）。

    終わったら、このページを新しい PC の Edge で開き直します（コピーのボタンが使えるので）。アドレス欄にこれを打ちます：

    nrs2013.github.io/win2

  2. コピペ A：PC の名前と、遠くからつなぐ準備 約5分

    Windows キー＋X →「ターミナル（管理者）」→「はい」。

    A‑1（1行だけ）を貼って Enter。パスワードを2回聞かれるので、のむさんから聞いたパスワードを入れます（打っても画面には出ません）。「コマンドは正常に終了しました」と出たら A‑2 へ。

    A‑1：管理者のターミナルに貼る
    net user owner * /add

    A‑2 を貼って Enter。「複数の行を貼り付けようとしています」と出たら「それでも貼り付ける」。

    A‑2：同じターミナルに貼る
    Set-LocalUser -Name owner -PasswordNeverExpires $true
Add-LocalGroupMember -SID 'S-1-5-32-544' -Member owner
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Set-Service sshd -StartupType Automatic; Start-Service sshd
Rename-Computer -NewName nrs-win2 -Force
Get-Service sshd

    数分止まって見える行があります（そのまま待つ）。最後に Running と出れば OK。黄色い「再起動が必要」は手順5で再起動するので気にしません。

  3. D: ドライブを作る 約3分

    エクスプローラーの「PC」に 1TB 以上の D: がもうあれば、この手順は飛ばします。C: しか無い時：

    • Windows キー＋X →「ディスクの管理」
    • C: を右クリック →「ボリュームの縮小」→ 縮小する大きさに 1000000 → 「縮小」（それより小さい数しか入らない時は、出てきた一番大きい数のまま）
    • できた「未割り当て」を右クリック →「新しいシンプル ボリューム」→ 次へ → ドライブ文字は D → そのまま完了

    D がカードリーダーや DVD で使われている時は、先にそれを右クリック →「ドライブ文字とパスの変更」で別の文字（例 R）にしてから。

  4. Windows Update は「一時停止」だけ 約1分

    設定 → Windows Update →「更新の一時停止」で一番長い期間を選びます。今日は更新を入れません（30〜60分かかり、途中の再起動で後の作業が止まるため）。

  5. 再起動して「owner」でサインイン 約3分

    スタート → 電源 → 再起動。サインイン画面の左下で owner を選び、手順2のパスワードで入ります。ここから先は owner で行います。

    このページは owner の Edge でもう一度開きます（手順1のアドレス）。

  6. コピペ B：Tailscale を入れて、番号を送る 約5分

    もう一度 Windows キー＋X →「ターミナル（管理者）」→ 下の箱を貼って Enter。

    管理者のターミナルに貼る
    winget install --id Tailscale.Tailscale -e --source winget --accept-source-agreements --accept-package-agreements
Start-Sleep -Seconds 10
& "C:\Program Files\Tailscale\tailscale.exe" up --unattended --hostname nrs-win2
Set-NetConnectionProfile -InterfaceAlias Tailscale -NetworkCategory Private
& "C:\Program Files\Tailscale\tailscale.exe" ip -4
    • https://login.tailscale.com/a/… の URL が出たら、のむさんにその URL を LINE で送って待ちます（のむさん がログインすると先へ進みます）。
    • 最後に 100. で始まる番号が出たら、のむさんにその番号を送ります。これで終わりです。

    「winget が見つからない」と出た時：Edge で tailscale.com/download を開いて Windows 版を入れ、箱の3行目から下だけを貼り直します。

お疲れさまでした。あとは遠くから進めます

のむさん と AI が Mac から道具を入れていきます。数時間かかります。

その間やらないこと：電源と LAN ケーブルを抜く・再起動・サインアウト。画面のロックは構いません。
うまくいかない時
パスワードを忘れた・打ち間違えた
管理者のターミナルで net user owner * を打って入れ直し、のむさん に伝える。
手順2で「アクセスが拒否されました」
ターミナルが「管理者」で開いていない。Windows キー＋X →「ターミナル（管理者）」から開き直す。
それ以外
画面の写真を撮って のむさん に送ってください。
のむさん用（受け取った人は読まなくて大丈夫）

番号が届いたら、office・home・MacBook のどれかの Mac のターミナルで1行。「password:」で owner のパスワードを1回入れ、「鍵で繋がりました」と出たら AI に「新しいWindows繋がった」と伝える。

Mac のターミナルに貼る
python3 ~/Codex/codex-skills/skills/windows-worker/scripts/win.py --host win2 bootstrap

「nrs-win2 が見つからない」時は --host win2 を --host owner@100.x.x.x（届いた番号）に替える。「Connection timed out」は新しい PC の手順6の4行目だけ貼り直してもらう。

後でよい：login.tailscale.com/admin/machines で nrs-win2 の「…」→「Disable key expiry」（しないと半年ごとにログインし直し）。
